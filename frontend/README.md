# Frontend — Murf AI Voice Agent Web UI

Next.js (App Router) frontend interface built with LiveKit Agents UI, Tailwind CSS, and TypeScript.

## 🚀 Quickstart

### 1. Install dependencies

```bash
cd frontend
pnpm install
```

### 2. Configure environment

Copy `.env.example` to `.env.local`:

```bash
cp .env.example .env.local
```

Required keys:

- `LIVEKIT_URL`
- `LIVEKIT_API_KEY`
- `LIVEKIT_API_SECRET`

### 3. Run development server

```bash
pnpm dev
```

Visit `http://localhost:3000`.

---

## 🎨 Customization

Custom branding, colors, visualizers, and features are configured in `app-config.ts`.
